# Apache SkyWalking (apache-skywalking)
Apache SkyWalking is an open-source APM system that provides monitoring, tracing, and diagnosing capabilities for distributed systems in cloud native architectures. It supports auto-instrumentation for Java, .NET, Python, Go, Node.js, and PHP.

## APIs

### Apache SkyWalking API
SkyWalking provides a GraphQL query API for trace, metrics, and log data, gRPC APIs for agent reporting, a REST API for health checks, and agent APIs for auto-instrumentation in Java, .NET, Python, Go, Node.js, and PHP.
