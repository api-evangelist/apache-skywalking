Background Previously, if you wanted to monitor a Golang application in SkyWalking, you would integrate your project with the go2sky project and manually write various frameworks with go2sky plugins. Now, we have a brand-new project ( Skywalking Go ) that allows you to integrate your Golang projects into SkyWalking with almost zero coding, while offering greater flexibility and scalability. In this article, we will guide you quickly integrating the skywalking-go project into your Golang project.
